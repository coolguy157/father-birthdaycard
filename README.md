A high-fidelity, interactive **AI Code Editor & Copilot Simulator** built specifically to celebrate your Dad's birthday!

---

## 🚀 How to Open and View
1. Open the project folder in File Explorer: `c:\Users\matth\Documents\antigravity\kind-euclid`
2. **Double-click `index.html`** to open it instantly in Chrome, Edge, Safari, or Firefox (zero dependencies or server required!).

---

## ✨ Features & Interactive Elements

1. **⚡ Vibe Code & Run:**
   - Clicking the green **"⚡ VIBE CODE & RUN"** button compiles the birthday protocol, generates real-time streaming terminal logs, triggers celebratory sound effects, and bursts confetti!

2. **🤖 Interactive Copilot AI (DadCopilot):**
   - Click the prompt chips (*"✨ Vibe Coder Poem"*, *"🎂 Bake Cake"*, *"🤣 10x Dad Joke"*, *"☕ Refill Coffee"*, *"🏆 Performance Review"*).
   - Or type **any custom prompt** into the chat bar for real-time responses!

3. **🎂 Neural Birthday Cake Studio (Live Canvas):**
   - Switch to the cake tab to view the glowing cyber birthday cake.
   - **Click the cake / candles** to blow them out (with smoke physics and wish counters) or relight them!
   - Customize frosting shaders (*Cyberpunk Blue*, *Matrix Green*, *Sunset Amber*, *Chocolate*).

4. **🎵 8-Bit Chiptune Birthday Anthem:**
   - Click **"Play Birthday Chiptune"** in the top bar to hear a synthesized retro 8-bit polyphonic "Happy Birthday" track built with the Web Audio API.

5. **📸 RAG Memory Vault (Photo Embeddings):**
   - Drag & drop or click the dropzone to upload real photos of your Dad/family. They'll be automatically embedded into the vector card gallery with cosine similarity scores!

6. **💌 Birthday Letter Modal:**
   - Click **"Open Birthday Letter"** in the top header.
   - You can click the signature to customize your name/sign-off or edit the message.
